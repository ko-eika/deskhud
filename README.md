# DeskHud

可切换 **宠物包**（皮肤 + 行为）与可配置 **HUD 插件** 的桌面宠物（egui）。支持社区打包与多语言。

## 运行

```powershell
cd C:\Users\eika\work\deskhud
cargo run -p deskhud-egui
```

- 拖动桌宠；右键：选择宠物 / 打开 HUD 配置。
- 默认宠物：大眼球，眼睛跟随全局鼠标。

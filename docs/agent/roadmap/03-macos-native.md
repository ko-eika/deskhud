# macOS 原生窗口

状态：进行中；目标 1 主窗口基础已完成，当前转入目标 2 独立气泡窗口

## 总目标

使用 AppKit/Core Animation 或 Metal 完成宠物、菜单、气泡、HUD 合成和 HUD 布局窗口。设置窗口暂保留 `winit + egui_glow`。

## 目标清单

- 目标 1：宠物主窗口
- 目标 2：气泡/对话框独立原生窗口
- 目标 3：右键菜单
- 目标 4：HUD 合成窗口
- 目标 5：HUD 布局窗口

---

## 目标 1：宠物主窗口

### 目标效果

macOS 使用原生窗口/合成承载宠物主窗口，先建立透明、局部命中、拖拽、置顶和生命周期基础；右键菜单依附于该窗口的命中与坐标能力。

### 实现范围

- AppKit/Core Animation 或 Metal 宠物窗口。
- 宠物窗口的透明背景、局部命中和鼠标事件路由。
- 拖拽阈值、越界移动、松手吸附与位置持久化。
- 宠物置顶偏好、窗口尺寸、Retina、多显示器和退出清理。
- 宠物包绘制、行为事件、切换和刷新接线。

### 验收标准

- [x] 宠物主窗口使用 macOS 原生窗口/合成路径，不依赖 egui 控制窗承载透明宠物。
- [x] 宠物窗口透明、窗口命中和输入路由正常；不要求透明部分鼠标击穿。
- [x] 拖拽跨过阈值后才开始，允许拖出工作区，松手后正确吸附/修正并保存位置。
- [ ] 左键按下、释放、点击、拖拽事件及键盘事件按契约传给宠物包（移至目标 2 验证）。
- [x] 置顶切换只跟随 prefs，设置窗口保持普通层级。
- [x] 宠物包切换、行为、尺寸和显示刷新正常。
- [ ] Retina 缩放、负坐标多显示器、显示器切换和退出清理正常（多显示器场景待验证）。

### 验证状态

状态：目标 1 基础功能已验收；键鼠事件移至目标 2，多显示器场景待验证

- 验证平台：macOS 开发环境。
- 已验证：macOS 可启动；原生透明 `NSWindow + NSView`、动画、拖动、右击、菜单关闭和退出清理已验收；workspace Clippy 已通过。
- 当前状态：原生窗口、透明、动画、拖动、贴边、置顶、宠物包切换、行为绘制、尺寸刷新和退出清理已验证。
- 未验证：键鼠事件契约（移至目标 2）以及 Retina 负坐标多显示器、显示器切换场景。

### 已知问题

- 问题：曾启用 AppKit 系统窗口拖动时，贴边会触发 macOS 的窗口平铺/布局白框。
  - 解决方法：关闭 `setMovableByWindowBackground` 和 `setMovable`，改由原生视图自行处理拖动；按下记录起点，超过 4pt 阈值后移动，松手再吸附/修正并保存。
  - 修复状态：已解决，macOS 验证通过。
- 问题：临时气泡绘制会因窗口尺寸和生命周期不匹配而闪现。
  - 解决方法：目标 1 阶段暂不绘制临时气泡，统一等待目标 2 的独立 AppKit 气泡窗口。
  - 修复状态：已移除临时绘制。
- 说明：按键和鼠标提示不在目标 1 验收，统一放到目标 2 独立对话框完成后验证。
- 说明：贴边检测由平台/宿主提供 `DockState`，宠物包自行决定反馈；蓝点包已补齐四边与角落的明显颜色反馈，引擎不写死贴边外观。
- 验证情况：目标 1 除键鼠事件和多显示器场景外已通过；目标 2 负责独立气泡及键鼠提示验证。

## 目标 2：气泡/对话框独立原生窗口

macOS 使用独立 AppKit 窗口承载 `PetPaint` 的气泡/对话内容、样式和位置；实现方式与 Windows 现有独立 dialogue HWND 和合成器路径对齐。

### 目标效果

气泡独立于宠物主窗口显示，不裁剪宠物窗口、不通过频繁扩缩宠物窗口承载对话，并随宠物包状态实时显示、隐藏和定位。

### 实现范围

- 独立透明 AppKit 工具窗口和原生绘制视图。
- `PetPaint` 气泡文字、颜色、圆角、尾巴和主题映射。
- 宿主负责屏幕避让、穿透、层级、刷新和退出清理。

### 验收标准

- [ ] 气泡使用独立 AppKit 窗口，不依赖宠物主窗口绘制。
- [ ] 气泡内容、样式、显示/隐藏随宠物包状态更新。
- [ ] 宠物移动、贴边、置顶和切换时气泡位置与层级正确。
- [ ] 气泡不接收鼠标，不影响宠物命中和拖拽。
- [ ] Retina、多显示器、屏幕边界避让和退出清理正常。

### 验证状态

状态：待实现

### 已知问题

- 问题：当前气泡仍临时绘制在宠物视图中，尚未迁移为独立 AppKit 窗口。
  - 修复状态：目标 2 待实现。

### 验收标准

- [ ] 菜单全部功能可用。

- [ ] HUD 总开关关闭时布局入口禁用；置顶和 HUD 状态勾选实时正确。
- [ ] 菜单从宠物窗口右键位置正确弹出，不遮挡或改变宠物窗口几何。
- [ ] 菜单失焦、Esc、再次右击、打开设置、返回宠物和重复打开流程稳定。

# Linux 原生窗口

状态：待推进

## 总目标

优先实现 X11 原生窗口与合成；根据 Wayland 合成器能力提供明确降级。设置窗口暂保留 `winit + egui_glow`。

## 目标清单

- 目标 1：宠物主窗口
- 目标 2：右键菜单
- 目标 3：HUD 合成窗口
- 目标 4：HUD 布局窗口

---

## 目标 1：宠物主窗口

### 目标效果

X11 下实现透明、局部命中、输入、拖拽、贴边和置顶；Wayland 不支持时明确降级。

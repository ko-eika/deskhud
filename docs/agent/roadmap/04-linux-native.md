# Linux 原生窗口

状态：待推进

## 总目标

优先实现 X11 原生窗口与合成；根据 Wayland 合成器能力提供明确降级。设置窗口暂保留 `winit + egui_glow`。

## 目标清单

- 目标 1：宠物主窗口
- 目标 2：气泡/对话框独立原生窗口
- 目标 3：HUD 合成窗口
- 目标 4：HUD 布局窗口

---

## 目标 1：宠物主窗口

### 目标效果

X11 下实现透明、局部命中、输入、拖拽、贴边和置顶；Wayland 不支持时明确降级。

### 验收标准

- [ ] X11 透明、窗口命中和输入路由正常；不要求透明部分鼠标击穿。
- [ ] 普通单击不会误触发拖拽。
- [ ] 拖拽跨过阈值后才开始，允许越出工作区，松手后正确贴边/修正并保存位置。
- [ ] 左键、右键、键盘及拖拽事件按契约传给宠物包；宠物包切换、行为、尺寸和刷新正常。
- [ ] 置顶切换只跟随 prefs，设置窗口保持普通层级。
- [ ] 多显示器、负坐标、DPI 和退出清理正常。
- [ ] Wayland 能力不足时有明确降级。

## 目标 2：气泡/对话框独立原生窗口

### 目标效果

使用宿主管理的独立透明工具窗口承载宠物包气泡，不裁剪宠物主窗口，并随宠物状态实时显示、隐藏和定位。

### 实现范围

- 独立平台原生气泡窗口与平台绘制后端。
- `PetPaint` 气泡文字、样式、尾巴和主题映射。
- 屏幕避让、穿透、层级、刷新和退出清理。

### 验收标准

- [ ] 气泡使用独立原生窗口，不依赖宠物主窗口绘制。
- [ ] 气泡内容、样式、显示/隐藏随宠物包状态更新。
- [ ] 宠物移动、贴边、置顶和切换时气泡位置与层级正确。
- [ ] 气泡不接收鼠标，不影响宠物命中和拖拽。
- [ ] 多显示器、缩放、屏幕边界避让和退出清理正常。

## 目标 3：右键菜单

### 目标效果

使用 Linux 原生菜单完成设置、置顶、插件开关、布局和退出操作。

### 验收标准

- [ ] X11 菜单功能和定位正常。
- [ ] 菜单文案完整来自 i18n；中文/英文切换后文案、缺键回退和字体显示正确。
- [ ] 主题、字体、置顶勾选、HUD 总开关勾选和布局禁用状态正确。
- [ ] 设置、置顶、插件开关、HUD 布局和退出动作正确，菜单与设置窗口生命周期分离。
- [ ] 菜单与宠物窗口生命周期分离；菜单不改变宠物窗口几何。
- [ ] 菜单失焦、Esc、再次右击、打开设置、返回宠物和重复打开流程稳定。
- [ ] 菜单显示期间宠物保持正确置顶关系，设置窗口不被设为置顶。
- [ ] 菜单退出和应用退出时无残留窗口、输入捕获或崩溃。
- [ ] Wayland 不把不支持的能力伪装成已支持。

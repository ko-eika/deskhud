# 宠物包协议与规范

- 状态：进行中

## 总目标

定义宠物包的 manifest、资源、国际化、行为契约、版本兼容和打包规范，确保内置 Rust 宠物与未来社区 WASM 宠物遵循同一套宿主边界。

## 目标清单

- 目标 1：包格式与 manifest
- 目标 2：宠物行为与绘制契约
- 目标 3：资源、国际化与配置
- 目标 4：版本兼容与分发

---

## 目标 1：包格式与 manifest

### 目标效果

宠物包可通过目录或 zip 形式安装、发现、校验和加载。

### 验收标准

- [x] `.deskhud` 目录/zip 格式已建立。
- [x] `kind = "pet"` 已建立。
- [x] `id`、`version`、`engine`、`api_version`、显示元数据字段已约定。
- [x] `preview`、`icon`、`assets` 和 `entry` 路径规则已约定。
- [ ] 社区 WASM `entry` 的端到端加载完成。

### 验证状态

- 状态：内置包已验证，社区包待推进。
- 已验证：内置宠物包可扫描、注册和打包。
- 未验证：社区 WASM 宠物包完整加载。

### 已知问题

- 问题：WASM 宠物包入口和 Guest runtime 尚未完成。
- 修复状态：计划中。
- 验证情况：当前仅覆盖内置 Rust 实现。

## 目标 2：宠物行为与绘制契约

### 目标效果

宠物包可实现 tick、事件响应、配置和中性绘制，不接触窗口句柄、平台 API 或 egui。

### 验收标准

- [x] `PetKind`、`PetKindInfo` 和 `PetPaint` 已建立。
- [x] `tick`、`on_event`、`paint` 和配置选项已建立。
- [x] `PetEvent`、`PetPaintCtx`、Dock/Drag/Mouse 状态已建立。
- [x] 宠物包不直接操作 HWND、屏幕坐标或平台窗口。
- [ ] 更完整的中性 `PetFrame` 和社区 Guest ABI 完成。

### 验证状态

- 状态：进行中。
- 已验证：内置宠物包行为和 Windows 原生主窗口接线正常。
- 未验证：宠物包切换和社区 WASM 行为。

### 已知问题

- 问题：气泡样式和更完整的中性帧契约仍在演进。
- 修复状态：进行中。
- 验证情况：当前使用现有 `PetPaint` 及宿主独立气泡窗。

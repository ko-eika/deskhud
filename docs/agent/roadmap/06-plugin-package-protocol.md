# 插件包协议与规范

- 状态：进行中

## 总目标

定义 HUD 插件包的 manifest、贡献条目、帧数据、布局、国际化、开关和版本兼容规范，确保插件只输出平台无关 HUD 数据。

## 目标清单

- 目标 1：包格式与 manifest
- 目标 2：HUD 贡献与帧协议
- 目标 3：开关、布局与国际化
- 目标 4：版本兼容与社区扩展

---

## 目标 1：包格式与 manifest

### 目标效果

插件包可被发现、校验、注册，并声明自身 HUD 条目和资源。

### 验收标准

- [x] `.deskhud` 目录/zip 格式可复用。
- [x] `kind = "plugin"` 已建立。
- [x] 插件 `id`、版本、引擎兼容族和 ABI 字段已约定。
- [x] HUD 条目 `id`、label、默认开关和 icon 规则已建立。
- [ ] 社区 WASM 插件入口端到端加载完成。

### 验证状态

- 状态：内置插件已验证，社区插件待推进。
- 已验证：插件注册、条目发现和设置页展示。
- 未验证：社区 WASM 插件加载和隔离。

### 已知问题

- 问题：WASM runtime 和插件 Guest ABI 尚未完成。
- 修复状态：计划中。
- 验证情况：当前仅覆盖内置 Rust 插件。

## 目标 2：HUD 贡献与帧协议

### 目标效果

插件通过 `HudFrame` 输出文本、面板等中性视觉数据，不创建窗口、不绘制 egui、不接触平台 API。

### 验收标准

- [x] `Plugin`、`HudContribution`、`HudFrame` 和 `HudVisual` 已建立。
- [x] 文本/面板中性视觉原语已建立。
- [x] 运行态按每屏一个 HUD 合成窗的规则已建立。
- [x] 插件帧可被 Windows 原生 HUD 后端消费。
- [ ] 更完整的帧协议和社区 Guest ABI 完成。

### 验证状态

- 状态：进行中。
- 已验证：HUD 可正常渲染，插件调整后可更新。
- 未验证：所有平台原生后端和社区 Guest。

### 已知问题

- 问题：布局模式窗口销毁、退出重绘和鼠标穿透仍有问题。
- 修复状态：进行中，记录在各平台 native 文档。
- 验证情况：Windows 已观察到，macOS/Linux 待对应平台迁移后验证。

## 目标 3：开关、布局与国际化

### 目标效果

插件总开关、条目开关、布局和文案目录可独立配置并稳定持久化。

### 验收标准

- [x] 启用条件为总开关 ∧ 插件 ∧ 条目。
- [x] `HudSlotLayout` 仅包含 `x/y/scale`。
- [x] 插件和条目 prefs 键规则已建立。
- [x] `plugin.<id>.*` i18n 命名空间已建立。
- [ ] 选中 HUD 的右键操作菜单和重置大小完成。

### 验证状态

- 状态：进行中。
- 已验证：开关、布局持久化和插件设置接线。
- 未验证：退出布局后的完整刷新和右键操作菜单。

### 已知问题

- 问题：选中 HUD 尚无重置大小入口。
- 修复状态：计划中。
- 验证情况：计划通过右击选中的 HUD 显示操作菜单。

# macOS 多窗口重绘冻结

## 现象

打开宠物右键菜单后，宠物动画可能停止；从菜单打开设置后，菜单 hover 和勾选状态可能冻结。

## 原因记录

macOS 路径曾将多个窗口的绘制状态、事件转发和 GL 生命周期混在同一个宿主状态机中。控制面切换后，主窗口仍可见，但没有持续获得独立的重绘调度；菜单/设置也可能只在创建或首次绘制时更新。

## 修复要求

- 宠物、菜单、设置使用独立窗口状态与重绘节奏。
- 任意控制窗口打开时，宠物帧循环不能暂停。
- 设置打开时，菜单不应承担设置页面的事件或渲染状态。
- 每个 `egui_glow` painter 在对应窗口销毁前调用 `destroy()`。
- 窗口销毁和重建不得复用已失效的 GL 资源。

## 验收

1. 宠物右键打开菜单，宠物动画持续播放。
2. 菜单打开设置，菜单 hover 不冻结，设置控件状态持续更新。
3. 关闭设置和菜单后，宠物仍可右键打开新窗口。

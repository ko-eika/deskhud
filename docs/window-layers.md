# 分层窗口交互说明（Native 覆盖层）

> 描述 DeskHud 在原生覆盖层下的**四类独立窗口**的生命周期、职责、展示/销毁时机与相互联动。
> 铁律：三/四类窗口彼此独立，不互相塞内容；平台只消费中性场景/命中契约（HWND 不进入包/引擎）。

## 总览

| 窗口 | 职责 | 生命周期 | 出现条件 |
|------|------|----------|----------|
| 主窗口 | 只渲染宠物 | 程序运行全程常驻 | 永远存在 |
| 气泡/对话框窗 | 对话气泡 | 按需创建、按需隐藏 | 宠物包行为产出气泡 |
| HUD 信息窗 | 合屏显示所有 HUD 条目 | 有启用条目时存在 | 总开关 ∧ 插件 ∧ 条目 |
| HUD 布局窗 | 调整 HUD 位置/大小 | 进入布局模式创建、退出销毁 | 进入布局编辑模式 |

---

## 1. 主窗口（宠物）

- **渲染内容**：只画宠物（身体/眼睛/气泡尾部等由 `PetPaint` 提供的中性绘制）。
- **尺寸**：由宠物包（`PetKind`）尺寸决定；随宠物包切换而变化。
- **生命周期**：只要程序在运行就一直存在，不因打开/关闭其它窗口而重建。
- **位置与形态**：可拖动、贴边吸附（壳负责），置顶只随 prefs。

## 2. 气泡 / 对话框窗

- **渲染内容**：只有对话气泡（皮肤/透明度/尾巴/文字），由宠物包行为触发展示。
- **形态**：独立透明工具窗，**不是**受父客户区裁剪的 `WS_CHILD`。
- **生命周期**：按需——宠物包有气泡要展示时显示，无则隐藏；宿主负责屏幕避让、层级、穿透与生命周期。
- **联动**：首次显示可能影响 DWM 排序，需重新提交宠物 + 气泡共同层级（现有实现已在做，`gpu_overlay_probe.rs:194-201`）。

## 3. HUD 信息窗

- **渲染内容**：所有**已启用** HUD 条目合成的信息。
- **合成策略**：每屏一个合成窗、同层绘制——同屏所有启用条目合入**这一个** HUD 层，不做"每条 HUD 一个窗"。
- **尺寸/覆盖**：收缩到**所有启用 HUD 条目的合并包围盒**。即每个已启用条目按自身 `slot_layout` 算出覆盖框，HUD 信息窗的大小=这些覆盖框的合并边界。
- **命中/穿透**：HUD 信息窗整体为**展示型、可点击穿透**——只显示 HUD 信息、不遮挡其下其它窗口的鼠标操作。即包裹液条目的点击被穿透交给下方应用，HUD 信息窗不拦截交互（与可交互 HUD 的相对应，参见 `OverlayHitRegion` 的 `Interactive`/`Passthrough` 语义）。
- **生命周期**：任一启用条目存在即有；总开关 / 插件 / 条目全关则无（销毁）。
- **坐标与尺寸**：条目按 `slot_layout(x/y/width/height)` 定位并独立调整宽高，参照活动区；旧 `scale` 仅用于读取兼容。

## 4. HUD 布局窗

- **内容**：进入布局模式时展示全部 HUD slot，含选中边框、移动、右下角缩放柄，用于调整位置和大小。
- **生命周期**：进入布局模式创建展示；**退出编辑模式时销毁**。
- **关键联动（与 HUD 信息窗互斥切换）**：
  1. 进入布局模式 → **HUD 信息窗暂时销毁**，改由布局窗接管展示。
  2. 在布局窗内调整各 HUD 位置/大小并持久化。
  3. 退出布局模式 → **布局窗销毁**，根据更新后的 HUD 信息**重建新的 HUD 信息窗**。

---

## 联动时序澄清

- 主窗口与气泡窗长期独立，不随布局进出变化。
- 布局模式开关只在 **HUD 信息窗 ⇄ 布局窗** 之间互斥切换，不触碰宠物/气泡窗。
- 所有建/销都不泄漏 OS 类型到引擎/包契约。

## 置顶策略（对所有窗口适用）

- **宠物与 HUD 分别跟随各自的层级设置（`pet.global.layer` / `hud.global.layer`）**：层级统一支持置顶、正常、置底；气泡跟随宠物，HUD 布局编辑期间临时置顶。
- 置顶**只在 prefs 变化时**设置一次，**勿每帧调用 `WindowLevel`**（铁律，见 `CONSTRAINTS.md`：勿每帧对合成窗 `WindowLevel`；同帧 Close+置顶易 AV）。
- 层级联动注意：勿用 owner 或临时取消某窗置顶形成层级循环；气泡跟随宠物层级。
- 例外：设置窗始终不置顶（铁律）。菜单在显示期间可临时位于宠物之上，仍按原约束处理。本策略描述宠物 / 气泡 / HUD 信息窗 / HUD 布局窗四类的置顶判定。
